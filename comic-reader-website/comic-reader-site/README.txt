SHE & I — MULTILINGUAL COMIC WEBSITE

CONTENTS
- index.html, style.css, script.js: website files
- comics/english.pdf: English edition
- comics/tamil.pdf: Tamil edition
- comics/malay.pdf: Malay edition

PREVIEW
Open index.html in a modern browser. For the best local preview, use a simple local web server; PDF preview behavior can vary when opening a file directly.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in to https://github.com/ or create a free account.
2. Create a new public repository named comic-reader (or another name).
3. Upload the contents of this folder. Make sure index.html is at the repository root and the comics folder is included.
4. Open the repository's Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose the main branch and /(root), then Save.
7. Wait for GitHub Pages to publish. Your public URL will be:
   https://YOUR-USERNAME.github.io/comic-reader/
8. Open that URL on your phone. Copy it into Instagram > Edit profile > Links > Add external link.

LANGUAGES
This package currently includes English, Tamil, and Malay because those are the three PDFs supplied. Tanglish is not included yet. If you want Tanglish instead of Malay, provide a Tanglish PDF and replace comics/malay.pdf, or ask to change the third language button.

NOTES
- All three PDFs are stored in the site, so visitors can read them without signing in.
- Anyone with the website URL can access the comic files. Only publish PDFs you have permission to share publicly.
- GitHub Pages is free for public repositories, subject to GitHub's current usage terms.
